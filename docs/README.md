## Sobre

BabelChat é uma plataforma que tem como objetivo conectar pessoas interessadas em praticar diferentes idiomas, oferecendo funcionalidades de criação de perfil, gerenciamento de interesses, publicação de posts, adição de amigos e um sistema de chat interativo. Este site contém a documentação e os artefatos desenvolvidos pelo Grupo 02, na Primeira Entrega do projeto da disciplina de Arquitetura e Desenho de Software, ministrada pela professora Milene Serrano no segundo semestre de 2025, na Universidade de Brasília.
