## Introdução

Para explorar as funcionalidades essenciais de uma plataforma de aprendizado de idiomas, foi utilizada a técnica de introspecção. Este método envolveu uma imersão nos pontos de vista de usuários arquetípicos — as personas — para antecipar suas necessidades, desejos e cenários de uso. O estudo se aprofundou em três perfis distintos, que representam as principais motivações para o aprendizado de uma nova língua na plataforma:
1.  Sofia, a Estudante Dedicada: Jovem universitária que precisa atingir a fluência em um idioma para fins acadêmicos e exames de proficiência. Busca eficiência e parceiros de estudo sérios.

2. Carlos, o Profissional Ocupado: Gerente em uma multinacional com pouco tempo, que precisa melhorar suas habilidades de conversação em um idioma para reuniões de negócios e avanço na carreira. Busca flexibilidade e conteúdo específico.

3. Helena, a Viajante Curiosa: Freelancer que ama cultura e está aprendendo um idioma por hobby, para uma futura viagem. Busca uma experiência divertida, casual e cultural.

Ao simular a jornada de cada persona, foi possível levantar requisitos funcionais e não-funcionais cruciais para o desenvolvimento de uma plataforma que seja ao mesmo tempo flexível, prática e conectada aos interesses de cada um.

## Metodologia

A introspecção foi realizada por [Guilherme Moura](https://github.com/Guilherme-Moura). O processo consistiu em, com base no perfil de cada persona, imaginar-se utilizando a plataforma em seus contextos específicos: Sofia buscando um parceiro focado para praticar para exames de proficiência; Carlos procurando uma sala temática sobre negócios em seu intervalo; e Helena explorando um chat em grupo sobre cultura italiana. A técnica focou em aspectos que valorizam a usabilidade, a qualidade da conexão e o engajamento de cada perfil de usuário.


Após a coleta individual dos requisitos, os resultados foram organizados em duas tabelas: 

> Legenda das Tabelas 1 e 2:

- IRFx: Requisito Funcional da Introspecção nºx
- IRNFx: Requisito Não-Funcional da Introspecção nºx

### Requisitos Funcionais 

Na **Tabela 1**, a seguir, são detalhados os requisitos funcionais identificados durante a introspecção.

<font size="3"><p style="text-align: center"><b>Tabela 1:</b> Requisitos Funcionais.</p></font>


| ID     | Requisito Funcional                                                                                             |
|--------|-----------------------------------------------------------------------------------------------------------------|
| IRF01 | O sistema deve permitir que o usuário crie um perfil indicando idiomas de interesse e seu nível de proficiência. |
| IRF02 | O sistema deve permitir a busca por parceiros de conversação com base em filtros de idioma, nível e tópicos de interesse. |
| IRF03 | O sistema deve oferecer chats em dupla (1-a-1) e em grupo (salas temáticas).                                     |
| IRF04 | A plataforma de chat deve suportar comunicação por texto, áudio e vídeo em tempo real.                           |
| IRF05 | O sistema deve registrar o tempo de conversação do usuário e conceder conquistas por marcos atingidos. |
| IRF06 | O sistema deve permitir que o usuário compartilhe suas conquistas em redes sociais externas (ex: LinkedIn, Instagram). |
| IRF07 | O sistema deve permitir que um usuário possa bloquear ou denunciar outro usuário por comportamento inadequado. |
| IRF08 | O sistema deve fornecer uma ferramenta de autoavaliação de nível para guiar o preenchimento do perfil.  |
| IRF09 | O sistema deve permitir que os usuários favoritem parceiros de conversação para futuras interações.  |


<font size="3"><p style="text-align: center"><b>Autor:</b> [Guilherme Moura](https://github.com/Guilherme-Moura), 2025.</p></font>

### Requisitos Não Funcionais

Abaixo, na **Tabela 2**, os requisitos não funcionais que foram elicitados a partir do método da introspecção.


<font size="3"><p style="text-align: center"><b>Tabela 2:</b> Requisitos Não Funcionais.</p></font>


| ID      | Requisito Não-Funcional                                                                                     |
|---------|-------------------------------------------------------------------------------------------------------------|
| IRNF01 | O sistema deve possuir uma interface intuitiva, permitindo encontrar uma conversa em menos de 3 minutos.      |
| IRNF02 | O sistema deve ter alta disponibilidade para conectar usuários em diferentes fusos horários.           |
| IRNF03 | A latência em chats de áudio e vídeo deve ser mínima para garantir uma conversação fluida.                    |
| IRNF04 | O sistema deve garantir a privacidade das conversas e a segurança dos dados dos usuários.                   |
| IRNF05 | O sistema deve ser responsivo e compatível com os principais navegadores de desktop.               |
| IRNF06 | A interface da plataforma deve estar disponível em múltiplos idiomas.                   |
