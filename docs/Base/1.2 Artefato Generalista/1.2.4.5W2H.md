# 5W2H <a id="artefato"></a>

## Introdução

O **5W2H** é uma ferramenta de gestão e planejamento utilizada para organizar ideias e estruturar ações de forma clara e objetiva.  Seu nome deriva das iniciais em inglês de sete perguntas essenciais: **What, Why, Where, When, Who, How e How much**. Com base nessas questões, é possível definir **o que será feito**, **por que será feito**, **onde será feito**, **quando será realizado**, **quem será responsável**, **como será executado** e **quanto custará**. Esse método auxilia equipes a transformarem estratégias em planos de ação bem definidos. Além disso, favorece a comunicação, reduz ambiguidades e facilita o acompanhamento das atividades. Sua simplicidade torna o 5W2H aplicável em diferentes áreas, desde projetos acadêmicos até processos empresariais. Assim, gestores e equipes ganham maior **clareza, foco e eficiência** na tomada de decisões. Em resumo, o 5W2H é uma técnica prática para transformar ideias em resultados mensuráveis.

<font size="3"><p style="text-align: center"><b>Tabela 1:</b> 5W2H</p></font>


| Pergunta | Descrição |
|----------|-----------|
| **What (O quê?)** | O projeto Correio Digital é uma aplicação web que tem como objetivo principal conectar pessoas que desejam aprender um novo idioma. O site terá um sistema para os usuários se conectarem e criarem grupos, a fim de realizarem conversas na língua desejada. Além disso, o site contará com um sistema de publicações onde os usuários podem compartilhar e curtir conteúdos relacionados a língua estrangeira, um chatbot para tirar dúvidas quanto ao uso do site e a função de criar um perfil |
| **Why (Por quê?)** | A principal motivação do projeto é fazer com que pessoas que queiram aprender uma nova língua possam achar um parceiro para praticar conversação de maneira intuitiva e descomplicada |
| **Where (Onde?)** | O site ficará hospedado em um domínio na internet |
| **Who (Quem?)** | O público-alvo inclui qualquer pessoa interessada em aprender um novo idioma |
| **When (Quando?)** | Ao longo do segundo semestre de 2025 da UnB, que tem duração de agosto até dezembro |
| **How (Como?)** | O desenvolvimento da plataforma será utilizando tecnologias como typescript, html, css e tailwind para o front e python para o backend |
| **How Much (Quanto?)** | Não haverá custo financeiro para a produção da plataforma |
