## Introdução

Léxicos são conjuntos de termos específicos usados em uma área particular, para descrever conceitos. Eles incluem vocabulário técnico e especializado que é essencial para a comunicação eficaz dentro desses contextos específicos, estabelecendo uma linguagem compartilhada entre os profissionais e membros da comunidade. O léxico é uma forma controlada e organizada de definir todos os termos do domínio que o software precisa tratar. Ele é muito útil para documentar requisitos de forma clara e consistente.

## Metodologia

Para criar os léxicos, empregamos a metodologia do **Léxico Ampliado da Linguagem (LAL)**. Os símbolos do **Correio Digital** foram identificados a partir do uso do sistema e dos requisitos elicitados na etapa anterior. Após identificados, eles foram ordenados e descritos como: noção e impacto.

### Tabela 1 – Léxicos do tipo LAL

| Tipo do símbolo | Noção                                                                       | Impacto                                                                         |
| --------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| **Sujeito**     | Quem é o sujeito                                                            | Ações que executa                                                               |
| **Verbo**       | Quem realiza, quando acontece e quais os procedimentos                      | Quais os reflexos das ações no ambiente e novos estados decorrentes             |
| **Objeto**      | Definir o objeto e identificar outros objetos com os quais ele se relaciona | Ações que podem ser aplicadas ao objeto                                         |
| **Estado**      | O que indica e ações que levaram a esse estado                              | Identificar outros estados que podem ocorrer a partir do estado que se descreve |

## Relacionamento dos Léxicos

<p style="text-align: center"><b>Tabela 11</b> - Relacionamento dos Léxicos</p>

| Léxico                                      | Relaciona-se com                              | Descrição do Relacionamento                                                      |
| ------------------------------------------- | --------------------------------------------- | -------------------------------------------------------------------------------- |
| <a id="anchor_L01" href="#L01">L01</a>: Estudante         | L02: Mensagem; L04: Enviar; L06: Arquivar     | Estudante é o agente central que cria, recebe e organiza mensagens.              |
| <a id="anchor_L02" href="#L02">L02</a>: Mensagem          | L03: Caixa de Entrada; L07: Anexo; L09: Status| Mensagem é o objeto principal, armazenado, anexado e que assume diferentes estados |
| <a id="anchor_L03" href="#L03">L03</a>: Caixa de Entrada  | L02: Mensagem                                | Armazena mensagens recebidas pelo estudante.                                     |
| <a id="anchor_L04" href="#L04">L04</a>: Enviar Mensagem   | L01: Estudante; L02: Mensagem                 | Estudante gera mensagem e o sistema distribui para destinatários.                |
| <a id="anchor_L05" href="#L05">L05</a>: Notificação       | L01: Estudante; L02: Mensagem                 | Notificação alerta sobre mensagens recebidas ou ações pendentes.                 |
| <a id="anchor_L06" href="#L06">L06</a>: Arquivar Mensagem | L01: Estudante; L02: Mensagem                 | Estudante organiza mensagens, movendo da inbox para arquivo.                     |
| <a id="anchor_L07" href="#L07">L07</a>: Anexo             | L02: Mensagem                                | Arquivo associado a uma mensagem enviada ou recebida.                            |
| <a id="anchor_L08" href="#L08">L08</a>: Grupo             | L01: Estudante; L02: Mensagem                 | Estudantes agrupados trocam mensagens em comum.                                  |
| <a id="anchor_L09" href="#L09">L09</a>: Status da Mensagem| L02: Mensagem                                | Define a situação atual de cada mensagem no sistema.                             |
