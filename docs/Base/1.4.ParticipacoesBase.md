# 1.4. Participações (Base)

## Introdução

Este documento apresenta um relatório detalhado das contribuições e participações de cada membro da equipe **Correio Digital** durante a primeira entrega da disciplina de **Arquitetura e Desenho de Software**. O objetivo é documentar de forma transparente e rastreável o trabalho desenvolvido por cada integrante, garantindo visibilidade sobre as responsabilidades assumidas e os resultados entregues.

A documentação está organizada em três módulos principais, correspondentes aos focos estabelecidos para esta entrega:

- **Módulo Design Sprint (Foco 1)**: Documenta as participações na metodologia de Design Sprint, incluindo atividades como brainstorming, criação de mapas mentais, rich pictures, protótipos e validações
- **Módulo Artefato Generalista (Foco 2)**: Registra as contribuições na elaboração de artefatos generalistas como glossários, léxicos, diagramas causa-efeito e metodologias 5W2H
- **Módulo Modelagem BPMN (Foco 3)**: Detalha as participações na modelagem de processos utilizando a notação BPMN para as metodologias ágeis (Scrum, XP, FDD e Kanban)

> **Nota**: Para visualizar as participações em iniciativas extras desenvolvidas pela equipe, consulte os documentos: [Iniciativas Extras](./Base/1.5.IniciativasExtras/1.5.IniciativasExtras.md).

### Metodologia de Avaliação

Para cada módulo, foi criada uma tabela estruturada contendo:
- **Nome do Membro**: Identificação do integrante com link para seu perfil no GitHub
- **Contribuição**: Descrição das atividades e artefatos desenvolvidos
- **Significância da Contribuição**: Avaliação qualitativa (Excelente/Boa/Regular/Ruim/Nula) do impacto da contribuição para o projeto
- **Comprobatórios Claros**: Links diretos para commits, documentos, artefatos e outras evidências que comprovam as contribuições
